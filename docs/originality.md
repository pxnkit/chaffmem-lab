# Originality and release provenance

ChaffMem Lab is an independent implementation created for this repository.

## Release record

The repository began as an empty project. Source modules, schemas, fixtures, tests, interface code, documentation, and generated results were created for this release. No external repository was imported, and no third-party experiment output is represented as a ChaffMem Lab result.

## Included material

- Original source code
- Original synthetic benign fixtures
- Original documentation
- Original product interface
- Original generated social preview artwork
- Run artifacts generated by the repository

## Excluded material

The release does not bundle third-party source code, notebooks, prompts, prose, figures, experimental outputs, private datasets, or model weights.

## Clean-room rule

Broad software and research concepts may inform problem selection. Implementation details, identifiers, schemas, fixture wording, plots, and results must be independently designed and justified.

If a future contribution materially incorporates a published method, dataset, model, or codebase, the contributor must add:

- Scholarly citation
- Applicable software or data license
- Clear description of what was incorporated
- Compatibility and redistribution review

Removing a source name from documentation is not a substitute for attribution. When attribution is required, the contribution does not merge until it is present.

A future research manuscript still requires a conventional related-work review. This software release makes no claim that its broad problem framing or individual algorithm families are novel.
