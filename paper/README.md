# Research package

This directory separates hypotheses, implemented methods, observed smoke results, and untested conclusions.

The package is designed to support a future empirical paper. It is not a completed paper and does not claim acceptance, novelty, or statistical significance.

## Files

- `claims.md` maps every proposed claim to executable evidence or an untested status
- `threat_model.md` defines attacker capabilities, restrictions, knowledge, and scope
- `limitations.md` records current validity limits
- `ethics.md` defines responsible-use boundaries
- `dataset_card.md` documents the deterministic benign fixtures
- `model_card.md` documents the embedding and symbolic decision components
- `experiment_manifest.md` predeclares the smoke study and larger study matrix
- `reproducibility.md` gives artifact regeneration and verification procedures
- `artifact_checklist.md` tracks release readiness
- `error_taxonomy.md` defines failure categories used during analysis

Generated figures and tables must be produced from immutable raw run artifacts. Hand-edited result numbers do not belong in this directory.
