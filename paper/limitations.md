# Limitations

## Representation validity

The default signed feature-hash embedding is deterministic and inexpensive. It does not reproduce the geometry, multilingual behavior, or update lifecycle of a learned production embedding.

## Policy coverage

The included policies capture common bounded-store decisions through explicit reference implementations. Real systems may combine retrieval, summarization, user controls, external databases, and undocumented heuristics.

## Behavioral task

The symbolic decision sandbox isolates whether a retrieved record changes an action. This improves causal inspection but simplifies language generation, tool selection, uncertainty, and human oversight.

## Fixture scope

The default corpus is small, synthetic, benign, and written for auditability. It cannot represent the distribution or social context of natural user histories.

## Live demo

The public browser application uses a deterministic reference engine for immediate interaction. It is not the source of benchmark evidence. Publication analysis must use the Python artifact pipeline.

## Scale

The smoke profile is designed for a laptop CPU. The default exact vector path is not an approximate nearest-neighbor implementation and should not be treated as a production scalability result.

## Statistical status

Smoke outputs verify the pipeline and may reveal candidate effects. They do not support broad claims without the frozen multi-seed study, confidence intervals, effect sizes, and untouched test configurations.

## Security scope

The repository does not test a hosted assistant or named commercial product. A result in this benchmark is not evidence of a product vulnerability.

## Defense tradeoffs

Admission controls and retention weighting can reject legitimate repeated traffic or overprotect stale records. Legitimate topic growth, correction, and criticality noise require explicit evaluation.
